Considering the current unfortunate enshittification of mainstream app stores like Google Play, I've started to transition to primiarly using F-droid apps whenever possible.

I'm unfortunately still tied to Google Play for specific apps, especially Google Maps. But besides those few dependencies, I've been surprised at how much I've been able to move over to F-droid.

It's reassuring to know that all F-droid apps are open source and compiled straight from the source code, so you can trust that the app is not some randomly uploaded apk.

So far, some of my favorite F-droid apps are:

- [Syncthing-Fork](https://f-droid.org/en/packages/com.github.catfriend1.syncthingfork/) - dropbox-style file syncing for free
- [Librera Reader](https://f-droid.org/en/packages/com.foobnix.pro.pdf.reader/) - awesome e-reader app
- [Joplin](https://f-droid.org/en/packages/net.cozic.joplin/) - open source cross platform notes app
- [Localsend](https://f-droid.org/en/packages/org.localsend.localsend_app/) - easy wireless file transfer over LAN
- [Fennec](https://f-droid.org/en/packages/org.mozilla.fennec_fdroid/) - Firefox without telemetry
- [Saber](https://f-droid.org/en/packages/com.adilhanney.saber/) - handwriting app for notes
- [Heliboard](https://f-droid.org/en/packages/helium314.keyboard/) - open source keyboard with no telemetry, works completely offline, better for privacy, etc
- [Amaze File Manager](https://f-droid.org/en/packages/com.amaze.filemanager/) - open source file manager
- [Ankidroid](https://f-droid.org/en/packages/com.ichi2.anki/) - my favorite flashcards app
- [Capy Reader](https://f-droid.org/en/packages/com.capyreader.app/) - a simple RSS reader app
- [Kanji Dojo](https://f-droid.org/en/packages/ua.syt0r.kanji.fdroid/) - kanji writing practice app
- [Package Manager](https://f-droid.org/en/packages/com.smartpack.packagemanager/) - allows managing packages, and even allows for disabling app permissions that typically aren't changable (e.g. network permission). Requires Shizuku

There's still a few open source apps that I use that aren't on F-droid, such as [Lawnchair launcher](https://github.com/LawnchairLauncher/lawnchair/), [Shizuku](https://github.com/RikkaApps/Shizuku), and [InstallWithOptions](https://github.com/zacharee/InstallWithOptions), but so far I've been pleasantly surprised at how much of my device usage can be made independent from Google Play.
